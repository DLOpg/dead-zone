# DEAD ZONE

Jeu de survie post-apocalyptique développé avec Roblox Studio.

## État du projet

- **Version jouable de référence :** Green Valley, installateur de secours testé dans Roblox Studio.
- **Dépôt GitHub :** initialisé pour recevoir les scripts source.
- **Prochaine étape :** synchroniser les scripts de la version fonctionnelle, sans écraser la map et les systèmes déjà installés.

## Précautions

Sauvegarder le projet Roblox Studio en `.rbxl` avant chaque changement important. Les fichiers du dépôt ne constituent pas encore le projet Roblox complet.

## Priorités

Amélioration du relief et de la nature, bâtiments diversifiés, Camp Haven, PNJ principaux, quêtes, armes, HUD et mode créatif de test.
